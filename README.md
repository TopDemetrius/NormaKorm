# НормаКорм

Веб-застосунок для управління та оптимізації кормових раціонів птиці. Дозволяє зоотехнікам складати раціони, контролювати відповідність нормам поживних речовин та автоматично знаходити найдешевший або найякісніший склад корму за допомогою лінійного програмування.

## Можливості

- **Управління видами птиці** — довідник видів (бройлер, несучка тощо) та вікових груп з нормами поживних речовин
- **Інгредієнти** — каталог кормових компонентів з поживним складом, вологістю, ціною та максимально допустимою часткою
- **Раціони** — ручне складання раціонів, аналіз відповідності нормам (норма / попередження / порушення), підрахунок вартості
- **Оптимізація** — автоматичний підбір складу раціону методом лінійного програмування (мінімізація вартості або максимізація якості)
- **Ціни** — відстеження динаміки цін на інгредієнти з історією змін
- **Звіти** — генерація PDF-звітів по раціонах, інгредієнтах, цінах та результатах оптимізації
- **Авторизація** — реєстрація та вхід користувачів, захист сторінок

## Технології


Backend | Python 3.13, Flask 3.1 
База даних | SQLite (через вбудований `sqlite3`) 
Оптимізація | PuLP 2.9 (лінійне програмування) 
Генерація PDF | fpdf2 2.8 
Frontend | Vanilla JS, HTML/CSS 


## Встановлення та запуск

### 1. Клонувати репозиторій / розпакувати проєкт

```bash
cd прога
```

### 2. Створити віртуальне середовище

```bash
python -m venv .venv
```

**Windows:**
```bash
.venv\Scripts\activate
```

**Linux / macOS:**
```bash
source .venv/bin/activate
```

### 3. Встановити залежності

```bash
pip install -r requirements.txt
```

### 4. Запустити додаток

```bash
python run.py
```

Застосунок запуститься на [http://localhost:5000](http://localhost:5000).

При першому запуску автоматично:
- створюється файл `normakorm.db`
- виконується `schema.sql` зі структурою таблиць
- якщо присутній `seed_data.py` — база заповнюється початковими даними

## База даних

Основні таблиці SQLite:

| Таблиця | Призначення |
|---------|------------|
| `bird_types` | Види птиці |
| `age_groups` | Вікові групи всередині виду |
| `nutrients` | Поживні речовини (протеїн, енергія, амінокислоти тощо) |
| `nutrient_norms` | Норми (min/max) поживних речовин для вікової групи |
| `ingredient_categories` | Категорії інгредієнтів |
| `ingredients` | Кормові інгредієнти (ціна, вологість, макс. частка) |
| `ingredient_nutrients` | Поживний склад кожного інгредієнта |
| `rations` | Раціони (прив'язані до вікової групи) |
| `ration_ingredients` | Склад раціону (інгредієнт + % включення) |
| `price_history` | Історія цін на інгредієнти |
| `users` | Користувачі системи |

## Оптимізація раціону

Модуль `app/optimizer.py` використовує **PuLP** для вирішення задачі лінійного програмування:

- **Змінні**: частка кожного інгредієнта у раціоні (%)
- **Обмеження**: норми поживних речовин (min/max), максимальна частка інгредієнта, сума = 100%
- **Режими**:
  - `min_cost` — мінімізація вартості 1 кг корму
  - `max_quality` — максимізація поживної цінності при заданому бюджеті
